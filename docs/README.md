# 文档目录

文档按所有权和变更原因分区，而不是按写作时间堆放。

| 目录 | 回答的问题 | 主要读者 |
|---|---|---|
| `design/` | 游戏为什么存在，玩家体验和系统原则是什么？ | 设计、开发、内容 |
| `research/` | 历史主张依据什么，哪里确定、哪里有争议？ | 历史研究、内容、数据 |
| `architecture/` | 世界如何表示和运行，模块边界是什么？ | 开发、测试、工具 |
| `decisions/` | 为什么选择当前方案，替代方案为何暂缓？ | 所有长期维护者 |

研究文档可以保留矛盾和未决问题；机器可读历史数据则必须引用已经登记的研究主张。设计文档可以提出体验目标；架构文档负责说明如何满足目标，但不能悄悄改变设计原则。
