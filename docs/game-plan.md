# 《汉末浮生》正式游戏实施计划

> 状态：执行中
>
> 最近更新：2026-07-25
> 正式项目：`game/LateHan.Game.slnx`

## 已经完成

- 冻结旧分钟级洛阳原型的产品扩张，将其保留为技术验证和回归参考。
- 明确正式产品为日/旬/月推进的三国个人生涯与动态历史模拟。
- 建立独立的 Domain、Simulation、Content、Persistence、Avalonia App 和测试项目。
- 实现 360 日历、上中下旬判断和逐日推进。
- 实现战略地点、道路、坐标、地点类型和城内地点两层空间结构。
- 实现统一人物模型、六项能力、身份标签、性格、动机和位置。
- 加入 8 个战略地点、首批城内地点、24 名具名人物和 3 种开局身份。
- 实现旅行、城内移动、打听、训练、谋生、休整和 NPC 周期迁移。
- 实现人物认识层级、好感、信任、身份与地点准入、规则化日程、已知话题和约见承诺。
- 实现由人物、地点、身份、关系、日程、话题和约见共同生成的 `AvailableAction` 上下文菜单。
- 实现请求引见、预约未来会面、依约会面、通用交谈和具体话题交谈；守约与失约都会留下可追溯结果。
- 实现有限认知显示：未正式接触前不暴露人物能力与动机，未知人物不直接显示姓名。
- 实现城邑治安、粮价、繁荣、官府控制与道路风险；不同地方会在人物行动、玩家行为和结构性压力下形成差异。
- 实现人物目标、有限认知和逐日行动意图；人物每旬按稳定规则在当地施加治安、供给、影响或机会压力。
- 实现玩家旅行、打听和谋生对地方状态与道路风险的实际影响，以及逐城拆分、能够解释变化缘由的旬报。
- 实现旬边界聚合结算以及版本化 JSON 存档和读档；v3 保存社会关系、地方状态、道路风险、待结算压力和人物计划，并兼容迁移 v1/v2 存档。
- 实现三种身份各自的生涯机会、地点准入、行动成本和成长收益，以及声望、人脉、生计压力和每旬生活开销。
- 实现可完成或失败的 60 日阶段目标；三种身份均可通过自己的路径完成目标，完全旁观则会留下明确失败结果。
- 实现京畿流民、东道粮运和颍川征辟三条有日期窗口的局势分支；玩家可旁观其自行收束，也可在合适地点按身份采取不同介入方式。
- 实现 v4 存档，保存生涯与局势状态，并兼容 v1/v2/v3 存档补全新状态。
- 实现全中文可点击 Avalonia 界面，玩家不需要输入内部 ID。
- 完成 G1 真实窗口点击验收：蔡琰忙碌时只能预约，按期赴约后成为相识并增加好感与信任；郡府小吏在合适日期可直接请求引见王允。
- 完成 G2 真实窗口点击验收：郡府小吏谋生跨旬后，洛阳状态受玩家和在地人物共同影响；继续静观一旬，各城仍按不同人物活动产生分化，道路风险同步变化，逐城旬报保持可读且说明缘由。
- 完成 G3 真实窗口点击验收：生涯目标、声望、人脉、生计压力与三条局势日期可见；小吏身份机会由官署地点解锁，跨旬扣除生活开销；京畿流民局势出现后可选择登记安置，并同步改变目标进度、声望、人脉、地方压力和局势结局。
- 当前正式项目自动测试共 34 项通过；Release 构建 0 警告、0 错误，旧技术原型 88 项回归测试继续通过。

## 当前真实边界

当前版本是“产品方向纵向切片”，不是功能完备的游戏。

- 地图是可点击节点列表，尚未绘制道路连线和区域底图。
- NPC 已具有目标、有限认知、逐日行动入口、规则化日程和确定性迁移，但当前计划仍是每旬按稳定规则行动一次的最小模型，尚未形成基于资源约束、机会比较与多步承诺的完整计划系统。
- 人物互动已经来自世界状态，但话题传播、引荐网络、恩义偿还和长期关系演化仍是最小实现。
- 旬结算已改变治安、粮价、繁荣、官府控制和道路风险，但尚未模拟具体粮秣库存、人口、组织资产和可进入的地方机会。
- 三种身份已有不同的 60 日生涯路径、财富压力和局势介入方式，但目前仍是少量可重复行动模板，尚未形成多层职位树、复杂委托链、经营系统和战斗系统。
- 场景内容暂时在 C# 工厂中，尚未迁入可审计的外部历史数据和玩法数据文件。
- 存档只有一个本地槽位，尚未提供档位管理、迁移目录和确定性重放。
- 已有首个 60 日玩家目标和三条局势结局，但尚未提供复杂委托链、职位流转、经营、战斗和跨阶段生涯结局。

## 接下来准备做什么

### G1：让行动菜单来自世界状态（已完成）

1. 已增加认识状态、好感与信任、身份准入、话题、约见承诺和规则化人物日程。
2. 已定义 `AvailableAction` 查询，由在场人物、地点、身份、关系、日程、已知话题和约见生成中文按钮及受阻原因。
3. 已让初次接触可能被门禁或日程阻止，并可预约未来日期；守约和失约会改变或记录社会状态。
4. 已验收同一人物在不同身份、日期、关系和地点下显示不同可选行动，界面不使用硬编码人物专属按钮。

### G2：让旬结算真正改变地方（已完成）

1. 已建立城邑治安、粮价、繁荣、官府控制和道路风险状态，并在中文界面显示当前地方及可达道路状态。
2. 已建立人物目标、有限认知、人物计划状态和逐日行动入口；当前采用确定性的每旬最小行动计划，便于测试与重放。
3. 已让玩家旅行、谋生和打听消息形成待结算压力，由旬结算与人物行动、地方基础和道路压力共同聚合。
4. 已验收静观三旬后至少三座城形成不同状态；旬报能够区分并解释人物、玩家和资源压力造成的变化。

### G3：形成 60 至 90 日个人生涯（已完成）

1. 已给寒门士子、郡府小吏和游侠分别建立学舍、官署和市集中的身份机会，以及不同成本、能力收益、准入优势和生计困境。
2. 已加入声望、人脉、每旬生活开销、生计压力和可失败的 60 日阶段目标；守约、交游、训练、谋生与身份行动都能留下生涯结果。
3. 已加入京畿流民、东道粮运和颍川征辟三个不强制历史结果的局势分支，玩家可旁观、赶赴当地或按身份介入。
4. 已验收三种身份均可运行完整 60 日并完成不同目标；完全旁观会使目标失败且三条局势自行收束，积极介入会形成另一套可解释结果。

### G4：内容工程与历史校核（下一阶段）

1. 把地图、人物、道路、城内地点和历史初态迁入版本化数据文件。
2. 每条历史敏感字段记录来源、置信度、争议和玩法假设。
3. 建立交叉引用、重复 ID、路线连通性、日期边界和汉化完整性校验。
4. 验收：场景无需重编译即可扩展，未知史实不会被伪装成精确数字。

## 阶段完成标准

每个阶段必须同时做到：领域规则有自动测试、Release 构建零警告、真实桌面界面走通主路径、计划文档如实更新、提交并推送。新增表现不得越过领域边界直接修改世界状态。
