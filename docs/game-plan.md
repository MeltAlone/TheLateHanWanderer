## 当前真实边界

当前版本是“产品方向纵向切片”，不是功能完备的游戏。

- 地图是可点击节点列表，尚未绘制道路连线和区域底图。
- NPC 已具有目标、有限认知、规则化日程和确定性多步计划，但候选事务目前只有粮储、钱财、人力与道路治安四类组织资源需求；尚无职位竞争、派系博弈、学习、结盟和婚姻等长期计划类型。
- 人物互动已经来自世界状态，NPC 之间已有由共同计划产生的共事关系；但敌对、竞争、师生、亲属、引荐、恩义偿还、羁绊和更长期的关系演化仍待建立，玩家关系与 NPC-to-NPC 关系也尚未统一到同一套图模型。
- 旬结算已改变治安、粮价、繁荣、官府控制、道路风险和 0..100 的资源账本；这些人口、粮储、府库和人力数值是由场景地方初态派生的 D 级玩法标定，尚未接入独立历史资源种子。
- 官署、士人网络、商旅和地方守备目前由已审计城内地点稳定生成，并已持有资产、应对地方缺口和发布委托；尚无独立场景审计记录、职位树及组织间关系网络。
- 三种身份已有不同的 60 日生涯路径、财富压力、局势介入方式和资源驱动委托方案，并已有第一版六类能力经验；当前每 10 点经验提升 1 点是便于验证的 D 级玩法标定，尚无学习难度、能力上限差异、技能、专长、伤病和衰老。
- 尚未实现羁绊、婚姻和家族系统。未来婚姻不能简化为配对按钮，必须同时受关系、年龄、身份、亲属、动机、名望、家族利益、政治局势和历史约束影响。
- 正式场景已外置并具备来源审计，但首版不少人物记录仍是按通用史传来源归类的 C/D 级材料，尚未为 24 人逐一完成传记主张、具体时点和位置的独立绑定。
- 存档只有一个本地槽位，尚未提供档位管理和迁移目录；核心世界已通过相同输入 90 日确定性重放，但尚无面向玩家的重放工具。
- 已有首个 60 日玩家目标和三条局势结局，但尚未提供复杂委托链、职位流转、经营、战斗和跨阶段生涯结局。

## 接下来准备做什么

### G1：让行动菜单来自世界状态（已完成）

1. 已增加认识状态、好感与信任、身份准入、话题、约见承诺和规则化人物日程。
2. 已定义 `AvailableAction` 查询，由在场人物、地点、身份、关系、日程、已知话题和约见生成中文按钮及受阻原因。
3. 已让初次接触可能被门禁或日程阻止，并可预约未来日期；守约和失约会改变或记录社会状态。
4. 已验收同一人物在不同身份、日期、关系和地点下显示不同可选行动，界面不使用硬编码人物专属按钮。

### G2：让旬结算真正改变地方（已完成）

1. 已建立城邑治安、粮价、繁荣、官府控制和道路风险状态，并在中文界面显示当前地方及可达道路状态。
2. 已建立人物目标、有限认知、人物计划状态和逐日行动入口；当前采用确定性的每旬最小行动计划，便于测试与重放。
3. 已让玩家旅行、谋生和打听消息形成待结算压力，由旬结算与人物行动、地方基础和道路压力共同聚合。
4. 已验收静观三旬后至少三座城形成不同状态；旬报能够区分并解释人物、玩家和资源压力造成的变化。

### G3：形成 60 至 90 日个人生涯（已完成）

1. 已给寒门士子、郡府小吏和游侠分别建立学舍、官署和市集中的身份机会，以及不同成本、能力收益、准入优势和生计困境。
2. 已加入声望、人脉、每旬生活开销、生计压力和可失败的 60 日阶段目标；守约、交游、训练、谋生与身份行动都能留下生涯结果。
3. 已加入京畿流民、东道粮运和颍川征辟三个不强制历史结果的局势分支，玩家可旁观、赶赴当地或按身份介入。
4. 已验收三种身份均可运行完整 60 日并完成不同目标；完全旁观会使目标失败且三条局势自行收束，积极介入会形成另一套可解释结果。

### G4：内容工程与历史校核（已完成）

1. 已把地图、人物、道路、城内地点、身份、话题和地方初态迁入 `189-central-plains.v1.json`，支持显式路径及 `LATEHAN_SCENARIO_PATH` 覆盖。
2. 已为每个敏感实体记录来源、字段覆盖、置信度、争议和玩法假设；没有史料精确支持的能力、坐标、日程和 0..100 初态均标为 D 级。
3. 已建立交叉引用、重复 ID、道路连通性、日期边界、数值范围、来源语义和汉化完整性校验；错误使用稳定的 `SCN-*` 编码。
4. 已验收外部 JSON 改名后无需重编译即可加载；坏引用、重复 ID、断路图、缺少中文、来源遗漏和越界数值均会在创建世界前拒绝。

### G5：让资源、组织与计划形成闭环（已完成）

1. 已为城邑建立人口、粮储、府库和可用人力账本，按旬结算，并明确标为 0..100 的 D 级玩法标定；90 日运行后至少三座城会形成不同资源轨迹。
2. 已让官署、士人网络、商旅和地方守备持有钱财、粮秣、人手与影响；玩家机会由组织需求和资源缺口生成，并具备接受、八日交付期限、完成、失约及十日冷却。职位与组织关系留待后续阶段。
3. 已让 NPC 在目标、有限认知、身份适配、组织资源、道路风险和行程约束下比较机会，形成评估、筹备、旅行、执行、完成/失败/取消及重新评估的多步承诺；玩家可协助或劝止。
4. 已验收 90 日资源与组织轨迹分化、玩家结果沿委托/账本/旬报解释、相同输入 90 日完整确定性重放、v6 存读档后计划续跑，以及真实桌面中的有限认知、协助、旬报和计划结算主路径。

### G6：人物成长与关系网络（进行中）

1. 已建立统一的六类经验来源和近期经历记录；行动、交游、共事、成功与失败不再只能直接加点，经验达到阈值后才改变当前能力。技能、专长、受教关系和成长难度仍待实现。
2. 已建立第一类 NPC-to-NPC 共事关系边，记录好感、信任、恩义、共同经历次数、日期和原因；敌对、竞争、敬畏、师生、亲属与引荐关系仍待扩展。
3. 已让 NPC 当前能力进入机会评分和计划结算，让同组织执行中的可信同伴提供协力；界面按认识层级控制成长与私下关系信息。下一步要让关系影响机会传播、请求帮助、举荐和人情偿还。
4. 已完成学习与共事第一条纵向闭环。后续依次加入受教/传授、求助/偿还人情、关系衰减与冲突，再在此基础上定义可涌现的羁绊。

### G7：文斗与武斗冲突解析、卡牌表达

1. 建立统一冲突解析层，文斗与武斗分别消费人物能力、技能、经历、状态、装备、关系支援和场地条件；卡牌是可读、可选择的战术表达，不是脱离世界模拟的独立小游戏。
2. 文斗可覆盖辩论、说服、品评、审讯和交涉；武斗可覆盖单挑、切磋、护卫和小规模遭遇，不在本阶段模拟军团战争。
3. 卡牌来源于人物实际掌握的技法、观点与经历，并带有出牌条件、反制、气势/体力成本和长期后果；胜负之外允许退让、平局、负伤、失言、结怨与声望变化。
4. 用确定性牌序种子与完整战报保证存读档和重放一致，并为 AI 使用与玩家使用同一套规则。

### G8：职位、羁绊、婚姻与家族

1. 建立组织职位树、任免资格、职责、俸禄、上下级和派系关系，使个人计划能够围绕求职、履职、升迁、辞官与背叛展开。
2. 羁绊由共同经历、长期关系、价值观与关键选择涌现，提供计划协作、冲突支援和特殊互动，但不取代底层关系数值与事件记录。
3. 婚姻建立在年龄、性别与时代规则、相识过程、双方意愿、家族关系、身份门第、经济条件、政治利益和历史审计之上；婚约、成婚、拒婚、守寡、再婚与姻亲影响都进入世界状态。
4. 家族以成员、亲属边、共同资产、声望、居所和继承关系存在，并与组织、地方资源、历史局势和人物计划互相作用。

## 阶段完成标准

每个阶段必须同时做到：领域规则有自动测试、Release 构建零警告、真实桌面界面走通主路径、计划文档如实更新、提交并推送。新增表现不得越过领域边界直接修改世界状态。
