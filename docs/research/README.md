# 历史研究入口

历史研究的任务不是为游戏寻找装饰性典故，而是建立模拟世界所依赖的初始约束。

## 当前研究范围

首个切片聚焦中平六年（189）八月何进遇害前夕，空间范围从雒阳城扩展至河南尹东部和陈留方向。选择这一窗口的原因是：朝廷、禁军、外兵、地方官署和人物关系都处于高张力但尚未完全锁定的状态，适合检验时间、空间、信息、命令与因果系统。

## 研究产物分级

```text
原始史料与现代研究
        ↓
来源记录（source）
        ↓
历史主张（claim，可冲突）
        ↓
研究结论（assessment）
        ↓
场景采用值（scenario value）
```

任何阶段都不得跳过来源直接生成“史实数据”。场景必须说明自己采用了哪条主张，以及如何处理未知部分。

## 当前重要限制

- 在线古籍页面只作为检索和复核入口，正式数据仍需与可靠点校本核对。
- 《郡国志》的户口数据早于 189 年数十年，只能作为行政规模基线。
- 古今地名对齐必须结合历史地图和 GIS，不能直接使用现代城市中心点。
- 首个切片的干支日期已经用中研院转换服务和儒略日数算法交叉校验，但场景仍以汉代纪年为规范时间，西历日期必须标注历法口径。
