# 场景数据

场景是模拟在某一时刻加载的完整世界状态。它由历史主张、明确推断、玩法抽象和固定随机种子共同生成。

每个场景必须声明：

- 历史日期及历法解释；
- 覆盖的空间范围；
- 引用的研究切片版本；
- 所有非史实填充值的生成规则；
- 随机种子与生成器版本；
- 已知缺口和不支持的系统。

场景不得把未知太守、人口或库存悄悄填成确定事实。

## 当前样例

- [`189-luoyang-crisis/`](189-luoyang-crisis/)：中平六年雒阳危机的四日命令行 MVP 夹具。其空间、数值和普通人物仍包含明确标注的玩法假设，不应作为历史数据库反向引用。

字段来源、ID、版本和加载规则见[场景数据契约](../../docs/architecture/scenario-contract.md)。
