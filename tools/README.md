# 工具目录

当前工具：

- `validate-scenario.ps1`：验证场景 JSON、版本、ID 唯一性、跨组件引用、数值边界和历史主张引用。

运行：

```powershell
./tools/validate-scenario.ps1
```

该脚本是内容管线的早期护栏，不属于未来模拟核心。正式实现后应由 `LateHan.Scenarios` 提供同等或更严格的跨平台验证，PowerShell 脚本可保留为仓库入口。

计划中的工具包括：

- 史料主张录入与来源校验；
- 历史地点和人物 ID 对齐；
- 场景构建与差异报告；
- 无玩家批量模拟；
- 事件回放、`why`、`trace` 和分叉比较；
- 数据置信度与未引用字段审计。

工具不得通过不可追踪的手工修补直接修改正式场景。
