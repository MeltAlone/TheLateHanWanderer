# 源代码目录

当前使用 C# / .NET 10，结构如下：

- `LateHan.Core`：纯模拟领域状态、行动、路径、访问、消息、稳定调度、确定性随机流、信念、计划、事件与指纹；
- `LateHan.Scenarios`：场景 JSON、校验、规范化哈希和领域构建；
- `LateHan.Persistence`：稳定快照 DTO（schema `1.1`）与原子文件持久化；
- `LateHan.Cli`：玩家命令和中文文本适配器。

当前 `wait`、移动、访问、交付和交谈都按事件边界推进。旅行具有持久行动实例和路段位置；门禁、访问队列、计划资源锁、凭证、消息谱系、信念、计划、L0-L3 精度、L3 群体、远方粮食账本和待重评人物脏集均可保存，王允可因正式报告自动复评并旅行。`stable-access-queue.v1` 只让具备资格、但因地点关闭或同分钟容量竞争而受阻的人排队；`exclusive-plan-resource.v1` 原子锁定计划资源，确定性处理等待、低优先级替换、取消和释放；群体成员升格使用稳定身份，只有没有独立因果负债的临时人物才能降格。`distant-batch.v1` 在低频边界结算 L3 生产/消费与关联 L2 人物背景周期，不逐分钟展开远方人口。

依赖方向只能指向核心。持久化、CLI 和未来图形引擎不得成为领域模型依赖。技术理由和复审条件见 [ADR-0003](../docs/decisions/0003-use-dotnet-for-simulation-core.md)。
